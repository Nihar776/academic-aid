# Academic Aid 🎓

A curated collection of automation scripts and utilities designed to streamline academic workflows, question paper retrieval, course material archival, and university portal monitoring.

---

## 📦 Projects Overview

| Tool | Directory | Description |
| :--- | :--- | :--- |
| **DBATU PYP Fetcher** | [`dbatu-pyp-fetcher/`](./dbatu-pyp-fetcher/) | Automated past-year question paper crawler & downloader for the Knimbus portal. |
| **DBATU Watcher** | [`dbatu-watcher/`](./dbatu-watcher/) | Automated university notification and circular watcher. |
| **NPTEL Downloader** | [`nptel-download/`](./nptel-download/) | Pipeline to download NPTEL course videos, transcripts, and reading materials. |
| **TOC PPTs Downloader** | [`toc-ppts-downloader/`](./toc-ppts-downloader/) | Downloads Sridhar Iyer's Theory of Computation lecture PPTs unit-wise. |

---
